# API Documentation

Base URL: `http://localhost:8000`

The API uses JSON. There is no authentication. `{id}` in a URL is the id of the game, player or score.

## Models

**Game**

| Field | Type | Rules |
|-------|------|-------|
| id | integer | generated by the database |
| title | string | required, unique, max 100 characters |
| genre | string | required, max 50 characters |

**Player**

| Field | Type | Rules |
|-------|------|-------|
| id | integer | generated by the database |
| username | string | required, unique, max 30 characters |

**Score**

| Field | Type | Rules |
|-------|------|-------|
| id | integer | generated by the database |
| player | integer | required, id of an existing player |
| game | integer | required, id of an existing game |
| points | integer | required, 0 or more |

Relationships:

- one player has many scores (one-to-many)
- one game has many scores (one-to-many)

Deleting a player or a game also deletes its scores.

## Games

### GET /api/games/

Returns all games.

Parameters: none

Response `200`:

```json
[
  {"id": 1, "title": "Tetris", "genre": "Puzzle"},
  {"id": 2, "title": "Snake", "genre": "Arcade"}
]
```

### POST /api/games/

Creates a game.

Parameters: none

Body:

```json
{"title": "Tetris", "genre": "Puzzle"}
```

Response `201`:

```json
{"id": 1, "title": "Tetris", "genre": "Puzzle"}
```

Errors: `400` if the data is not valid (see Errors below).

### GET /api/games/{id}/

Returns one game.

Parameters: `id` (in the URL)

Response `200`:

```json
{"id": 1, "title": "Tetris", "genre": "Puzzle"}
```

Errors: `404` if the game does not exist.

### PUT /api/games/{id}/

Replaces a game. All fields are required.

Parameters: `id` (in the URL)

Body:

```json
{"title": "Tetris", "genre": "Block puzzle"}
```

Response `200`:

```json
{"id": 1, "title": "Tetris", "genre": "Block puzzle"}
```

Errors: `404` if the game does not exist. `400` if the data is not valid (see Errors below).

### PATCH /api/games/{id}/

Changes only the fields that are sent.

Parameters: `id` (in the URL)

Body:

```json
{"genre": "Puzzle"}
```

Response `200`:

```json
{"id": 1, "title": "Tetris", "genre": "Puzzle"}
```

Errors: `404` if the game does not exist. `400` if the data is not valid (see Errors below).

### DELETE /api/games/{id}/

Deletes a game and its scores.

Parameters: `id` (in the URL)

Response `204` (empty body).

Errors: `404` if the game does not exist.

### GET /api/games/{id}/scores/

Returns the scores of one game, highest points first. The list is empty if the game has no scores.

Parameters: `id` (in the URL)

Response `200`:

```json
[
  {"id": 2, "player": 2, "game": 1, "points": 12000},
  {"id": 1, "player": 1, "game": 1, "points": 10000}
]
```

Errors: `404` if the game does not exist.

## Errors

**404 Not Found** - the game, player or score with this id does not exist. Example: `GET /api/games/999/`

```json
{"detail": "No Game matches the given query."}
```

**400 Bad Request** - the data is not valid. The response names each wrong field.

Example: `POST /api/games/` with a title that already exists:

```json
{"title": "Tetris", "genre": "Puzzle"}
```

```json
{"title": ["game with this title already exists."]}
```

Example: `POST /api/scores/` with an unknown player and negative points:

```json
{"player": 999, "game": 1, "points": -5}
```

```json
{"player": ["Invalid pk \"999\" - object does not exist."], "points": ["Ensure this value is greater than or equal to 0."]}
```
